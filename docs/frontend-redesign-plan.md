# 前端優化提案（已確認並實作）

以目前已接通真實 GPU 與 Ollama 的控制平台為基礎，只修改前端的視覺與操作層。

## 使用者與主要操作

- 使用者：同時維護幾個 AI 專案的個人開發者。
- 主要操作：查看 GPU 與任務狀態、提交推論、讀取結果及處理等待。
- 保留：總覽、任務、主機、模型四個檢視，以及所有現有 API 與排程語意。

## 建議方向：深色運算工作台

- 深灰工作區、深色導覽、綠色主要操作；不用霓虹光暈、漸層與裝飾背景。
- Workbench 版型：精簡摘要列、每張 GPU 各自一張設備圖卡、工作佇列與結果具明確層級。
- 一般資訊 14–16px；模型與數字使用等寬字，中文維持系統字型。
- 主機長名稱與模型 ID 可換行；狀態同時顯示文字與圖示。
- 任務詳情優先顯示生成文字；排程說明與原始資料使用可展開區塊。
- 表單以模型與提示詞為主，優先級等設定漸進揭露。
- 保留原生 dialog 的焦點鎖定與 Escape；補齊可見焦點、觸控尺寸、錯誤與連線狀態。
- 在 320／375／414／768px 和桌面尺寸驗證，手機工作列表改為可讀卡片。

## 備選：保留淺色

同樣的版型與互動優化，維持淺灰主工作區與綠色品牌，不切換整體明暗方向。
